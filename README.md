# Bash Log Analyzer

A Bash script for analyzing web server log files from the terminal.

The script provides an interactive menu that allows users to inspect common log statistics such as top IP addresses, requests per day, and HTTP status code counts.

---

# Features

- Analyze web server log files
- Display the top 10 IP addresses by request count
- Count requests per day
- Count HTTP status codes
- Interactive terminal menu
- Input validation for missing or invalid files
- Warning for files without a `.log` extension
